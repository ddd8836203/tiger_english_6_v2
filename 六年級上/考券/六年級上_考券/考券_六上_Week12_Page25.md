>
> 📐 **【句型公式 Sentence form】**：
> `<subject> + <verb “to be”> + <adjective + preposition> + <object> + because ...`
>
> 📦 **【Word Bank】**：`by` / `at` / `about` / `in` / `with` / `of` / `for`
